# Super Agent

A Python AI agent (GPT-4o + ChromaDB RAG + Docker sandbox, ReAct loop). `super_agent.py` is v1; `super_agent_v2.py` adds human approval for code runs/saves, prompt-injection defenses, and cost/length limits. Needs a computer with Python + Docker and a paid OpenAI API key to run. Screenshots from the original notes are not included in this repo (kept in the workspace folder).
